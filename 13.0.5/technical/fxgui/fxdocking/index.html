fxdocking ¶

Dock panes in Qt Advanced Docking System, drawn as cards on the frame.

Needs PySide6-QtAds, installed beside the PySide6 it was built for; importing this module imports it, and nothing else in fxgui does. A window puts an FXDockArea where its body goes and docks its panes on it.

FXDockArea ¶

FXDockArea(parent: Optional[QWidget] = None, gap: int = PANE_GAP)

Bases: QWidget

Dock named panes around a body, one gap apart, in QtAds.

A pane's layout saves and restores as bytes. A layout restored before the first show waits for it, since the split is sized then.

Parameters:

Name Type Description Default

parent ¶

 Optional[QWidget]

The parent widget.

 None

gap ¶

 int

Pixels between panes, and from the panes to the edges.

 PANE_GAP

Examples:

>>> docks = FXDockArea()
>>> window.setCentralWidget(docks)
>>> docks.set_central(viewer)
>>> log_toggle = docks.add_dock("log", "Log", log, "bottom")

add_dock ¶
add_dock(
    name: str,
    title: str,
    widget: QWidget,
    area: str,
    *,
    beside: str = "",
    size: Tuple[int, int] = (1, 1),
    tab_with: str = ""
) -> QAction

Dock widget as the pane name on area; return its toggle.

area is "left", "right", "bottom" or "top": of the window, or of the pane beside. Without beside, a second pane on one side tabs with the first; tab_with tabs it behind that pane wherever it sits. size weighs the pane across and down at the first show.

Raises:

Type Description
ValueError

area is unknown, or no pane is named beside or tab_with.
clear_top ¶
clear_top(width: int, height: int) -> int

Return the top for a width x height card at the top right.

One gap in from the right edge, and one gap under the topmost pane title bar in that corner. A taller card covers the title bars below it rather than moving down past them, which lands it mid-window.

banner_host ¶

banner_host(widget: QWidget) -> QWidget

Return where a banner about widget goes: its app's dock area.

A floating pane's widget finds the area of the window it floats from. Without one, the dock area in the widget's app window, else that window.

restorable ¶

restorable(state: bytes, built: bytes) -> bool

Say whether the saved layout state may replace the layout built.

Not when it names other panes, which would close the ones it misses, nor when it tucks one in a side bar, which reopens it hidden.
